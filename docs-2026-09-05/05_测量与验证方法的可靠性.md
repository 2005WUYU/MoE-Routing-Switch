# 测量与验证方法本身怎样得到验证

本篇给出测量的正确性条件、抽样推导、数值误差边界、因果比较和统计检验。参考文献编号见第 02 篇。这里的“可靠”是针对明确估计对象、误差范围和适用条件，不是宣称一套工具对所有实现都无误。

## 1. 先固定估计对象，再编写采样代码

设完整训练状态为

\[
\mathcal X_t=(\theta_t,\text{optimizer state},b_t,\text{scheduler},\text{RNG},\text{numeric state}).
\]

它至少包括可训练参数、Adam 等优化器状态、负载均衡 bias、学习率日程、随机数、混合精度状态。模型使用额外缓存、EMA 或专家映射时，也要纳入记录。

固定输入对象为完整序列与位置；存在批次容量竞争时，对象是完整批次。对同一词表 id 的不同上下文不能视为同一输入。

建议明确保存三个不同估计对象。

| 估计对象 | 具体操作 | 回答的问题 |
|---|---|---|
| 本层 support 差 | 更新后参数和真实输入不变，只换本层旧、新专家集合，按统一协议重算门权重 | 本层选择改变带来的输出差 |
| 全网固定旧路由比较 | 所有离散路由固定为更新前结果，对更新后模型从头运行 | 整张旧计算图更新与全部路由改变的区别 |
| 端到端任务干预 | 在指定层替换输出，运行完整后续网络并比较平均损失 | 该次软件干预对任务的直接影响 |

这些对象不得共用一个含糊的 `route_energy` 字段。特别是本层旧路由重放的剩余项，包含真实 \(h_{t+1}-h_t\)，不能自动叫全网平滑项。

## 2. 恒等式通过，不足以证明程序正确

假设三个输出为 a、b、c。无论 b 是否正确，

\[
(c-a)=(b-a)+(c-b)
\]

都成立。因此仅检查 `full = smooth + switch`，只能检查张量对齐及计算操作，不能证明中间反事实 b 是所需输出。

必须有独立于该恒等式的参照。

### 2.1 分层验证次序

先用两专家常数输出验证闭式值；再用小维度线性专家，计算全部专家后按路由显式求和；最后比较生产稀疏 dispatch 与这个独立参考。参考实现应尽量不用生产版的同一个 gather、normalization 和排序函数，否则错误可能被共同复用。

验证应覆盖 normalized selected softmax、全局 softmax 后截取但不再归一化、选择 bias 与聚合分数分离，以及容量 mask。第一阶段可只支持第一种，但必须拒绝未支持配置，不能默默近似。

### 2.2 必须加入故意错误的测试

主动把旧路由编号错位、把旧门权重当成新门权重、交换 token 顺序、忽略一个容量 mask，然后检查工具是否报错。若恒等式仍通过而独立参照能发现错误，说明参照真正增加了约束。

第 08 篇附带的代码实际检查了“错误中间值仍满足恒等式”的情况。生产代码还需对真实分布式执行做同样的错误注入。

### 2.3 至少应满足的性质

在主 support 协议中，没有集合变化时，本层差应为零；加相同 always-on 输出不改变该差；选中权重和固定为 1 且专家完全相同时，任意 support 输出相同。最后一条不能直接推广到不归一化门：集合不同可能改变聚合总权重。

还要检查原始输入无更新的重复前向、真实前向与手动指定同一路由的重放、单次与分块计算、不同 token 排序还原，以及单机参考与多 rank 结果。

## 3. 数值路由翻转可以得到一个确定性判据

令参考分数为 z，实际分数为 \(\widehat z=z+e\)，且

\[
\|e\|_\infty\leq\varepsilon_{\rm num}.
\]

如果参考第 K 与 K+1 分数差为 m，并满足

\[
m>2\varepsilon_{\rm num},
\tag{1}
\]

则 Top-K 集合保持不变。

**证明。** 对任意参考选中 i 和未选中 j，有 \(z_i-z_j\geq m\)。扰动后差不小于 \(m-2\varepsilon_{\rm num}>0\)，因此不存在未选中专家超过已选中专家。

该判据也有工程限制。把 BF16 分数转换成 FP32 再排序，不能恢复已经丢失的信息；只用 FP32 Router 重新计算，仍可能接收低精度产生的 h。建议分别比较同一 h 下的高精度分数和高精度完整前向。只有得到分数误差的实际界，式 (1) 才有保证意义。

当误差无法确定上界时，可以报告经验翻转率，但不能写成数学证明。确定性 tie-breaking 应固定到全局 expert id，而不是依赖不稳定排序或当前 rank 上的局部顺序。随机性与可复现性注意事项见 R25。

## 4. 一步保存、插值和重放的工程约定

真实一步参数差是 \(\Delta\theta=\theta_{t+1}-\theta_t\)。扫描

\[
\theta(\alpha)=\theta_t+\alpha\Delta\theta
\]

回答沿这一已实现更新方向的函数变化，**不等于重新训练一次、把学习率改成 \(\alpha\eta\)**。重新执行优化器可能改变裁剪、权重衰减、moment、loss scaling、外部 bias 以及后续 batch，问题已不同。

负载 bias 可以单独冻结、单独插值或一起改变，三种协议须分开记录。若 bias 更新本身离散，连续插值只是诊断路径，不是真实算法的一步。

保存状态后，probe 前向必须不更新训练计数器、不改变优化器、不消耗随后训练的随机数。训练有 dropout 时可选关闭随机性的诊断模式，或保留训练模式但使用配对随机数。两种结果不能混合；关闭 dropout 测到的是相应确定性模型，不是完整随机训练过程。

每个 \(\alpha\) 点都从同一初始状态构造，不要在前一个插值模型上累积增量。模型共享权重、专家副本、参数扁平化或混合精度 master weights 都要保持同步。

## 5. 边界富集样本不能直接估计总体能量

近边界样本适合检查机制，但它改变了输入分布。建议保留两个面板：均匀抽取的总体面板，用于估计实际发生率和能量；按 margin 富集的机制面板，用于研究条件输出差。后者不能不加权地替代前者。

### 5.1 有限总体的无偏估计

固定 N 个可评估对象，每个真实能量为 \(e_i\)，目标

\[
J_N=\frac1N\sum_{i=1}^N e_i.
\]

令 \(I_i\) 表示对象是否被抽中，已知纳入概率 \(\pi_i=P(I_i=1)>0\)。使用

\[
\widehat J_{\rm HT}=\frac1N\sum_{i=1}^N\frac{I_i e_i}{\pi_i}.
\tag{2}
\]

条件于这组总体对象与其状态，

\[
E\widehat J_{\rm HT}
=\frac1N\sum_i\frac{E I_i}{\pi_i}e_i=J_N.
\]

这就是纳入概率加权的基本无偏性，参见 R24。该证明不要求各 \(I_i\) 相互独立。

如果采用相互独立的 Bernoulli 抽样，还可以写出

\[
\operatorname{Var}(\widehat J_{\rm HT})
=\frac1{N^2}\sum_i\frac{1-\pi_i}{\pi_i}e_i^2.
\tag{3}
\]

固定配额的无放回抽样存在协方差，需要二阶纳入概率，不能继续使用式 (3)。如果小 margin 样本被确定性保留、其他样本永不抽中，后者 \(\pi_i=0\)，总体 J 不可由这组数据无偏恢复。应加入覆盖全部对象的均匀抽样部分。

### 5.2 容量机制下的对象选择

存在 token drop 或 batch-coupled assignment 时，单独抽一部分 token 后重跑容量分配，会改变原始执行结果。应先保留完整批次执行，再抽取其观测；或以完整批次作为抽样对象。不能把抽样导致的容量变化解释为模型更新导致的路由变化。

## 6. 小步长与有限样本之间的矛盾怎样处理

第 03 篇的 \(J(\alpha)\sim\alpha\) 是分布平均下的局部结论。固定有限、无平局样本存在一个最小跨界阈值；低于它，所有样本都不换路由，经验 J 严格为零。

所以不能不断缩小 \(\alpha\)，然后把最后一段全零曲线解释为理论被否定。也不能给零值加任意 \(10^{-12}\) 后拟合对数斜率，所得结果主要由伪计数决定。

一个可执行的拟合协议是：先固定候选网格与拟合区间选择规则；要求区间内有足够独立序列和跨界事件，并检查大扰动下多次交换、上游跳变和高阶项；对同一序列的一组 \(\alpha\) 观测整体重采样，保留嵌套相关性。报告各个候选区间的敏感性，而不只展示最接近 1/2 的区间。

发生率可用带 offset 的事件计数模型或直接拟合概率曲线，能量可对配对总体估计量拟合，再在序列和 run 层级重采样。不同 \(\alpha\) 使用同一输入使曲线更易比较，但也意味着这些点不是独立样本。

若最小可测 \(\alpha\) 仍太大，不能确认渐近斜率。此时保留真实 \(\alpha=1\) 的直接量级与损失比较，它们仍能回答实际问题，不必强行先获得漂亮幂律。

## 7. 稀有事件需要多少样本

在独立 Bernoulli 近似下，事件概率为 p，样本 N，估计的相对标准误近似为

\[
\frac{\operatorname{SE}(\widehat p)}p\approx\frac1{\sqrt{Np}}.
\]

累计 100 个事件只对应约 10% 的相对标准误；约 95% 区间的相对半宽要达到 10%，需要约 \((1.96/0.1)^2\approx384\) 个事件，且仍依赖近似适用。

语言模型 token 共享序列、层和训练轨迹，不能直接把 token-layer 数当独立 N。应先按完整序列或批次汇总，再对独立 run 分层；观察到 384 个高度相关 token 事件，不等于获得上述精度。

零事件也不是概率等于零。在 N 次独立试验中，单侧置信度 \(1-\gamma\) 的上界为

\[
p\leq1-\gamma^{1/N}\approx-\log\gamma/N.
\tag{4}
\]

95% 时得到常用的约 3/N。若独立性无法成立，就不能套这个数。可以改用独立序列“是否发生至少一次”的指标，但估计对象变为序列事件概率。

### 7.1 均方量的置信保证还需要尾部条件

若独立序列级能量 \(E_s\in[0,Q_{\max}]\)，Hoeffding 给出

\[
P(|\overline E-E E_s|>\delta)
\leq2\exp(-2n\delta^2/Q_{\max}^2).
\tag{5}
\]

这是有限样本保证，但需要真实上界。仅将观测截断到 \(Q_{\max}\) 并不使原目标有界；还需报告尾部被截掉的量，或明确目标已经改为截断能量。对重尾能量，均值、条件均值、分位数和最大观测都应保留。

## 8. 任务损失验证的正对照与反例对照

把真实路由差 D 注入后续网络时，应至少配对比较不注入、注入 D、同范数随机方向和同范数连续更新方向。随机方向一般不会匹配真实 D 的梯度投影、协方差、token 相关性及表示分布，因此这个对照只回答特定方向比较，不证明“不连续本身”具有额外因果力量。

必要时再按 \(\nabla L^\top D\)、层位置和 token 组进行匹配，并分别测固定后续路由与自由后续路由。所有模型参数、标签、输入顺序和随机数应相同。

一个可靠指标还应通过以下反例：下游完全忽略变化子空间时，J 可大而损失差为零；强裁剪可让 J 小而质量差；ReLU 门可有 support change 而输出连续。指标若不能容纳这些情况，其解释范围就写得过强。

## 9. 软件干预、算法效果与因果中介是三个问题

### 9.1 单次软件干预

在同一状态下主动替换指定张量，运行其余代码，是明确可重复的受控比较。它能给出“这次替换导致的输出、损失差”。但该张量可能不属于任何合法训练路径上的表示，结论限于这个干预。

### 9.2 算法长期效果

从同一个 checkpoint 复制完整模型、优化器和数据状态，随机分配基线或候选训练规则，继续同样的训练长度。配对 run 的最终损失差用于估计该算法在这些起点上的效果。所有后续优化器变化都是算法作用的一部分，不能通过事后控制它们来轻易宣称只剩路由机制。

### 9.3 为什么不能简单做 do(J)

J 是大量路由差向量的平方范数汇总。同一个 J 可以对应完全不同的方向、位置和 token。仅指定“把 J 设为 0.1”，没有指定如何改模型或表示，因果干预并不唯一。

因此应定义具体操作，例如只把给定边界对的输出差乘以 \(\lambda\)，或开启确定的专家辅助损失，再测操作的效果。R23 的中介分析还需要额外识别假设；训练中的负载、专家差异、优化器状态常同时影响 J 与结果，也会被干预改变。

“加入 J 后算法开关系数变小”最多是与中介解释相容的证据，不能自动证明机制。更有力的组合是：随机化算法效果、直接张量干预、方向与精度对照、不同作用方式产生的一致结果，以及明确的反例测试。

## 10. 时间预测不能偷看未来

一步更新后的 J 不能用于声称预测同一步已经发生的 loss spike。预测系统应在 t 时刻只使用可获得的历史，预测 \([t+1,t+H]\) 或更后的窗口。

去趋势、阈值选择、特征标准化、模型选择均只能在训练折完成。相邻重叠窗口要隔开，不能随机拆 token 行。至少按 run 留出，并进一步留出宽度、训练阶段或算法配置。最终比较加入 J 前后的 Brier score、校准、precision-recall 与告警提前量；AUROC 不能独立评价稀有事件告警的实用性。

如果每 500 步测一次 J，就没有足够时间分辨率证明提前 10 步预警。用稀疏测量插值出来的峰值不能当作真实观测。去趋势后的高频变化也不等于周期振荡；周期性主张还需要稳定采样和频谱、相关时间方面的证据。

## 11. 如何做跨种子统计与否定结论

主要独立单位是训练 run。checkpoint、层、batch 和 token 是其内部重复观测，不能把数百万行日志变成数百万次独立实验。

小规模 3 个 seed 可用于发现实现问题和估计噪声，不能天然满足最终论证的统计功效。设配对最终差值的标准差为 \(\sigma_\Delta\)，希望检出实际重要差异 \(\delta\)，正态近似下

\[
n\gtrsim\left[\frac{(z_{1-\alpha/2}+z_{1-\beta})\sigma_\Delta}{\delta}\right]^2.
\tag{6}
\]

这只是设计近似；小样本、重尾或频繁发散时需重新评估。先用试验估计噪声，再锁定主结果和预算。不要先跑五个种子，再宣称五个对任何效应都足够。

主假设少量预先指定，多重比较按相应 family 控制错误率；其他层、阶段和指标列为探索性。失稳、OOM、超时和中止必须保留，不能只统计存活 run。

没有显著差异不等于证明没有影响。若要主张实际影响可忽略，先定义工程上重要的阈值 \(\delta_{\rm practical}\)，再证明对应置信区间上界不超过它。阈值应根据任务损失、吞吐和训练成本决定，不能把 J 占比 1% 当作普遍无害标准。

## 12. 工程验收清单与证据边界

| 验收项 | 通过条件 | 未通过时的结论 |
|---|---|---|
| 独立参考 | 稀疏生产前向与全专家参考逐对象匹配 | 不能解释 J |
| 无更新重复 | 在指定随机协议下误差处于事先测得数值底噪 | 先排除随机与数值变化 |
| 支持与权重 | support-only、weight-only、共同改变分开 | 不能称纯 support 差 |
| 编号与位置 | 更新前固定专家对及 token 身份可追溯 | 不能判断边界事件 |
| 深层分解 | 本层重放与全网固定路由分别输出 | 不能把局部剩余项称全网平滑 |
| 抽样代表性 | 总体面板或已知正纳入概率 | 不能报告总体发生率 |
| 时间可用性 | 预测量严格早于目标窗口 | 不能声称预警 |
| 统计独立性 | run 层级比较与预定留出 | 不能以 token 行数夸大证据 |
| 干预含义 | 明确实际改变的参数、向量、状态 | 不能用含糊 do(J) 描述因果 |

通过这些检查，证明的是测量与验证程序在所测范围内值得信任。它们不会自动把未观察到的真实 MoE 现象变成事实；下一步必须执行第 07 篇的目标模型实验。
