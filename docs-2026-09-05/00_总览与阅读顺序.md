# MoE 硬路由更新、训练稳定性与 μP 迁移：论证文档集

版本日期 2026-09-05。基于用户提供的两篇 Markdown 和 Echo 博客 HTML，核对公开论文，给出条件证明、反例、干预推导和真实实验方案。研究对象仍是原材料中的真实一步路由变化及其与训练、超参迁移的关系，没有将问题换成一般 MoE 性能综述。

## 1. 目前的核心判断

**需要证明，但不能只证明“Top-K 有不连续”。** 基础边界现象已有论文研究，我们也可以给出直接构造与条件证明。项目真正需要新增的证据，是目标训练系统里这些变化的真实量级、任务影响、尺度漂移，以及针对性干预的收益。

**已有工作不能替代完整目标系统验证。** 路由波动、连续化、MoE 参数化、多轴扩展和大规模超参迁移分别已有相关结果；它们并不等于同一个“微观更新能量问题”已经被完整证明或消除。第 02 篇逐项区分已有结论和未覆盖内容。

**数学上可以证明损害的可能性。** 本报告构造了一个两专家模型，普通分支梯度更新使固定路由损失下降，而真实重新选择后的总体损失增加，并将结果推进到有限 batch SGD。它是存在性证明，不是现代 LLM 典型行为的证据。

**候选方法的局部作用可以分析，长期作用仍要验证。** 边界一致性可以降低固定样本、固定候选路线的差，但不能自动保证实际 J、任务损失或全部边界差都降低。新增系数 β 是否跨宽度可迁移，取决于参数组学习率、前向尺度和函数 Jacobian，不能仅由损失除以 d 推出。

## 4. 本次推导中最影响实验设计的几项结论

第一，排序后的 K/K+1 gap 永远非负。跨界必须跟踪更新前固定专家编号；否则可能从日志设计开始就无法正确识别事件。

第二，只固定本层旧路由时，剩余更新仍可能接收上游跳变。局部定位与全网固定旧路由的连续比较需要同时保留。

第三，平方根规律是分布平均、特定路径与特定极限下的结论。不能由它推出时间振荡、真实步长失稳或宽度迁移失败。固定有限无平局样本在足够小步长下反而没有切换。

第四，精确重构恒等式不能单独验证重放实现。任意错误中间值也能重构；必须引入独立全专家参照、解析值和故意错误的检查。

第五，J 只含差向量的大小，遗漏任务方向及下游响应。因此它既不是一般失稳的必要条件，也不是充分条件；要研究的是指定模型族中的增量解释和干预价值。

第六，辅助训练的概率权重、抽样平均和参数尺度都有独立证明义务。只按 margin 估计跨界概率可能漏掉条件协方差；只按边界样本平均可能改变总体目标；只将 loss 除以 d 不能保证 β 迁移。

## 5. 论文、推导、数值与真实实验的边界

第 02 篇汇总 24 篇论文及 1 项官方工程文档，部分只核对元数据或摘要，部分核对正文和具体公式。没有声称完整精读背景中的全部 50 篇文献，也没有声称排除了同期未公开工作。

第 03—06 篇的独立推导给出了具体假设和证明。其中一些是标准数学工具的针对性应用，不能因为在此整理出来就声称首次发现。它们尚未经过独立同行审查，读者应按所列条件与步骤复核。

附带 Python/NumPy 脚本实际执行 20 项检查，20 项通过。全部为解析构造或小型数值验证，不含真实 MoE 预训练。没有模型 checkpoint、真实训练日志或集群运行结果，因此第 07 篇清楚标为待执行方案。

原始背景文件没有在这组新文件中被覆盖。新文档对背景的修正单独列明，不静默把原材料的说法改成既有结论。

## 7. 最先执行的真实项目工作

第一项真实项目工作应是实现并验收同一 checkpoint 的完整一步重放，先输出本层 support 差、全网固定路由差与精确任务损失差。只有可靠测到它们在实际步长下的量级后，再决定优先研究边界一致性、已有平滑方案、共享结构，还是聚合尺度、专家工作负载和数值机制。
