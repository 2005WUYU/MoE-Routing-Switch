# 测量定义与代码对应

依据上级目录的《MoE_H20_真实更新测量实验方案_2026-09-05.md》。正式实验取 Qwen3 原有的全部 48 层、128 专家、Top-8；没有新增共享专家。

## 一步与支持集

`train.py` / `adapters/cluster_train.py` 在第 t 次真实优化器更新之前调用 `PairedMeasurement.capture()`，更新完成后调用 `finish()`。Xₜ 表示已完成 t 次更新。测量输入不进入训练迭代器。

`routing.py` 接受完整旧、新专家集合。旧集合上的门值由当前 logits 重新 softmax；参考聚合按专家编号排序，并集内每个 token–专家只算一次。排序只是参考规约顺序，生产专家集合直接从 Megatron routing map 捕获。

Y₀=F(h₀,θ₀;A₀)，Y₁₀=F(h₁,θ₁;A₀)，Y₁=F(h₁,θ₁;A₁)。`metrics.update_terms` 先分别转 FP64，再计算 R=Y₁₀−Y₀、D=Y₁−Y₁₀，以及逐 token 的 S/J/C/T/H。特征归一化由实际宽度决定，Qwen 为 2048。R 叫“其余更新项”，它可以包含上游跳变。

J 的切换条件均值来自切换 token 的能量和除以切换计数；执行路径另记不切换位置的能量。H=‖h₁‖²/d，r_h=√(J/H)。H、T 或切换计数为零时，对应比值为 null；数据文件保留零事件，不添加 epsilon，不扣除噪声能量。

`boundary_terms` 固定旧第 K/K+1 名的专家对，使用实际旧/新输入、Router 权重计算 Router 项、上游项和交叉项。旧完整分数用于换入专家的 1-based 旧排名；结果保存全部换入排名直方图和多专家交换计数。

## 数值路径

- `execution`：训练实现实际输出，加同一 TE/dispatch 实现的旧支持集重放；同状态重复前向另记输出能量与损失差。
- `fp32_reference`：沿实际捕获输入，将实际执行权重值先转 FP32，再执行 Router、SwiGLU 和聚合。每层仅转换本地专家权重。
- `alpha_*`：独立完整 FP32 网络，参数来自分片 FP32 master 的 θ₀+α(θ₁−θ₀)。Embedding、QKV、QK Norm、RoPE、Attention、专家与输出头全用 FP32 IEEE 路径。α=0 产生自己的旧支持集，生产 BF16 端点另行比较。

`ieee_fp32` 对应 PyTorch 2.9 的 `fp32_precision` API，关闭 autocast 并在退出后恢复调用环境。标量差和规约为 FP64。各层抽取开头最多四个有效位置做 FP64 专家重放，记误差能量和与真实样本数。这些样本只估计数值误差，不代表总体分布。

## 完整网络与干预

全网旧集合评估每次从 Embedding 开始，各层在这条反事实路径的新输入上重新计算门值。它产生 L₁₀；实际路径产生 L₁。U=L₁₀−L₀，V=L₁−L₁₀，单位 nats/token。

单层干预只改指定 MoE 输出，下游正常重算。实际替换向量为旧集合输出减实际输出；随机方向以同样加法位置加入，逐 token 范数相同。随机数发生器按序列和重复编号独立初始化，不依赖 rank 排布，不消耗训练 RNG。

## 统计与文件

每个文档单独打包，同文档的相邻片段保留同一 group。有效位置 mask 同时用于能量、切换与任务损失。`statistics.py` 对组重采样，先合并各组分子分母，再计算条件幅度、r_h、J/T 与 PPL 比；每个 α 使用相同 seed 和排序后的 group ID，因此共用重采样索引。

一次大测量与窗口重合时只执行一次前向测量，再从逐 token 标量中筛选预定前 64 条，写为 `window_step_*`。报告不拿 1024 条的大测量均值充当窗口末步的 64 条均值。

逐层 `groups.jsonl` 保存 FP64 的位置数、S/J/C/T/H 和、J² 和、切换/多交换计数、边界项以及数值误差；`summary.json` 保存精确经验分位数、最大事件能量份额、排名分布、事件文档组数和区间。

第 512 步两个精度路径与八个 α 的每层 `tokens.npz` 保存 J（FP64）、替换数（uint8）、最大换入旧排名（uint8）。每个位置共 10 字节，位置顺序为 rank 顺序、rank 内序列顺序、序列内位置顺序。有效 mask、sequence、group 及三种损失保存于同一测量的 `network/tokens.npz`；据此可以还原 token 位置，重算 J 的分布与条件统计。它没有保存高维向量，也不声称能重建任意中间激活。

上述逐层 token 主体在正式规模下约 10.07 GB（不计 ZIP 压缩），另有组记录、损失与报告；没有依赖压缩后的偶然小体积才能放进 16 GB 结果项。训练 checkpoint 使用 Bridge 的单代保留，写入下一代完成后清理旧代。
